# Assignment 2 Description:
The assignment combined nonlinear GPS position estimation, classical machine learning, and deep learning. We used least squares and gradient descent to estimate receiver location, trained logistic regression models to predict student depression, and built both MLP and CNN models to classify MNIST digits. This showed how different modelling approaches perform across mathematical, tabular, and image-based problems.
